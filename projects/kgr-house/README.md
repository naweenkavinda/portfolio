# KGR House — Interactive 3D House Model

An interactive, walkable 3D model of a real house built from an architectural floor plan. Navigate the house using arrow keys on desktop or on-screen controls on mobile.

▶ **[Open the 3D model live](https://naweenkavinda.github.io/portfolio/projects/kgr-house/)**. Source: [`index.html`](index.html).

## What it does

- Renders a full 3D house from a 2D architectural floor plan
- Walk through rooms in first-person using arrow keys
- Collision detection prevents walking through walls
- Realistic procedural textures: teak doors, granite counters, porcelain tiles, wood-look flooring
- Outdoor environment with grass lawn, coconut palms, and mango trees
- Sky and lighting system with natural shadows
- Responsive: works on desktop and mobile browsers

## Tech

- **Three.js** — 3D rendering and scene management
- **HTML / CSS / JavaScript** — Single self-contained file, no backend
- **Procedural textures** — All materials generated in code, no external image assets

## Background

Built from an actual floor plan for a house in Anamaduwa, Sri Lanka. Room dimensions were read directly from the architectural drawing (12'×10' and 13'×14' bedrooms, 8' bathroom, 9'×14' car porch). The model includes six doors with correct swing directions, a dog-leg staircase, furniture placement, and locally relevant construction materials.

The entire model is a single HTML file that runs in any modern browser with no installation.
